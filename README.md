# iFriend – Contact Organizer (Work in Progress)

A Java console application for managing personal and business contacts — currently under active development.

> ⚠️ **Status: Ongoing.** Core data structures and the main menu are in place; CRUD operations (add, update, delete, search, list) are being implemented feature by feature.

## Planned Features

- **Add Contact** – Store contact ID, name, phone number, company, salary, and birthday.
- **Update Contact** – Modify details of an existing contact.
- **Delete Contact** – Remove a contact from the system.
- **Search Contact** – Look up a contact by ID, name, or phone number.
- **List Contacts** – Display all stored contacts.

## Tech Stack

- **Java** (JDK 8+), using only the standard library (`java.util.Scanner`)
- Console-based UI with a menu-driven navigation flow

## How to Run

```bash
javac ifrend.java
java ifrend
```
